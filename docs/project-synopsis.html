1. Introduction

Grace of Jesus Christ Ministries, located in Kitintale, Kampala, Uganda, has experienced steady growth in membership over the years. With this growth comes the need for more efficient and organized methods of managing member information. The church currently relies on manual, paper-based registration processes which are prone to errors, loss of data, and difficulty in data retrieval and analysis.

The church, with its slogan "An encounter with the Holy Spirit," holds Sunday services at 8:00 AM and has become a beacon of spiritual growth in the Kitintale community. As the congregation continues to expand, the administrative challenges of managing member data have become increasingly complex. Manual registration books, while functional in the past, no longer meet the needs of a modern, growing church community.

This project aims to develop a comprehensive church registration system that digitizes the entire registration process. The proposed system will not only capture member information but also facilitate better communication, enable serving opportunity tracking, and provide church leadership with valuable insights through analytics and reporting capabilities. The system is designed to be user-friendly, accessible on multiple devices including smartphones, and provides a seamless experience for both church members registering and administrators managing the data.

2. Abstract

This project presents a web-based Church Registration System developed for Grace of Jesus Christ Ministries – Kitintale. The system addresses the limitations of the current manual paper-based registration method by providing a modern, efficient, and reliable digital solution. The proposed system consists of two main components: a public-facing registration portal accessible via web browsers, and an administrative dashboard for church leadership to manage and analyze member data.

The registration portal implements a multi-step form that collects essential member information including full name, phone number, residence, birthday, serving preferences, and referral source. The system also includes features for tracking serving opportunities such as ushering, choir, playing musical instruments, and venue management. Optional features include birthday celebration tracking and WhatsApp group membership consent.

The administrative dashboard provides secure authentication for authorized personnel, real-time access to registration data stored in Firebase Firestore, statistical visualizations using Chart.js, and data export capabilities. The entire application is built as a Progressive Web App (PWA), allowing users to install it on their devices and access it offline when necessary. This system represents a significant improvement over traditional paper-based methods, offering better data security, accessibility, and operational efficiency.

7. Proposed System

The proposed Church Registration System is a comprehensive web-based application that completely replaces the manual paper-based process with a modern digital solution. The system is designed with two primary interfaces:

7.1 Registration Portal (Public Interface)

The registration portal is accessible to any visitor or member via a web browser. It features a 3-step registration wizard with the following capabilities:

Step 1 - Basic Information: Collects full name, phone number, residence, and registration status
Step 2 - Serving & Preferences: Captures birthday (optional), serving opportunities, WhatsApp consent, and referral source
Step 3 - Confirmation: Allows users to review and verify their information before submission

7.2 Admin Dashboard (Restricted Interface)

The administrative dashboard provides authorized church leadership with tools to manage registration data effectively:

  • Secure login with email and password authentication
  • Searchable and filterable list of all registrations
  • Statistical charts showing registration trends and demographics
  • Export functionality for downloading data
  • Real-time synchronization with cloud database

15. System Architecture

The application uses a serverless architecture hosted on Firebase Hosting. User registrations are stored in Firebase Firestore, a NoSQL cloud database. The admin dashboard authenticates users via Firebase Authentication and provides real-time access to registration data. Google Apps Script can be used to sync data with Google Sheets for offline backup and additional processing.
